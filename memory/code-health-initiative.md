**The pattern that unlocked it — "Design B" reference-borrowing** (use for the remaining subsystems): the subsystem **owns** all its GPU resources (images/pipelines/compute-pipelines/descriptor pool+sets+layouts/sampler/per-frame buffers) but **borrows by same-named reference** the things referenced heavily elsewhere — services (`context_`/`renderGraph_`/`gpuProfiler_`/`swapchain_`) AND the settings structs (`toneMappingSettings_` 57×, `bloomSettings_`, `taaSettings_`, `ssaoSettings_`) + exposure-output floats + `ssaoAvailable_`, which stay owned by `Renderer`. Same member names ⇒ relocated bodies compile verbatim; the 90+ serialization/portfolio/scene refs stay untouched. Key moves: `SsaoSettings`→`RuntimeSettings.h` (breaks the include cycle, since Renderer.h must include PostProcessStack.h for the by-value member); `frames_.size()`→a `frameCount_` member; `currentFrame_` set via `beginFrame()`; TAA jitter owned by the stack, returned via `advanceJitter()` (Renderer folds it into the projection and keeps the jittered matrices, since the main pass uses them); SceneColorHDR moved (it was created in `createPostProcessResources`); mixed methods split (`createComputePipelines` keeps depth-pyramid, delegates exposure; `createPostProcessResources` wrapped by `recreatePostProcessResources` for the interleaved depth-pyramid/ImGui-preview reset). Debug UI reads via accessors. **Execution strategy: "duplicate-then-switch"** — commit 1 builds the new class as standalone compiling (dead, duplicated) code; commit 2 rewires Renderer + deletes originals. Both green = two phased checkpoints without throwaway shims. The shared descriptor pool forces the move to be atomic (no partial green), which is why standalone-first was the safe path.

Two things made it safe and are worth repeating for any refactor of this size,
because the unit tests barely touch Renderer so "compiles and runs" is otherwise
the only signal: partition the file into top-level definitions and verify
reassembly reproduces the original **byte for byte** before moving anything, then
verify every definition still exists **exactly once** afterwards. It was clean in
the first place because shared file-local helpers already lived in
RendererInternal.h rather than an anonymous namespace.
